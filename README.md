# k8s-documentation
Repository to serve documentation for older Kubernetes versions

The original documentation kan be found in the repo [kubernetes/website](https://github.com/kubernetes/website).
And is made available under the [Creative Commons Attribution 4.0 International](https://github.com/kubernetes/website/blob/main/LICENSE) license.

This repo here contains the rendered documentation pages for some older Kubernetes versions that are no longer offered at the main [documentation site](https://kubernetes.io/releases/).

The content was created following the [instructions](https://github.com/kubernetes/website/blob/main/README.md) at the original repo.
